PROJ / 07 — 데이콘, 신입 시절

디자인 시스템 & 콘텐츠 표준화

디자인 시스템 구축과 콘텐츠 표준화 제안으로 기획~오픈 리드타임을 75% 줄인 프로젝트

B2C 웹 디자인시스템 개발협업
2022.04 – 2022.11
Background

코딩 교육 서비스의 UI를 설계하는 프로젝트로, 오프라인 교육으로 쌓인 자료를 온라인 콘텐츠로 전환하는 작업이었다. 2022년 11월 초기 서비스 런칭을 목표로 했다.

Problem

콘텐츠팀·개발팀 간 교육자료 관리가 비효율적이었다. 콘텐츠팀이 Jupyter Notebook으로 작성한 교육자료를 프론트엔드 코드로 구현해야 했는데, 노트북 파일을 '문제', '정답', '힌트'로 쪼개 3가지 파일로 저장하고 있어 양 팀 모두 부담이 컸다.

Process

Figma + Framer 기반 UI Kit을 구축하고 개발팀 연동 환경을 구성했다. Jupyter Notebook(.ipynb)을 1문제·5셀 구조로 표준화할 것을 제안해, JSON 5개로 파싱하는 방식으로 양 팀의 문제를 동시에 해결했다. 콘텐츠팀은 파일을 쪼개 저장할 필요가 없어졌고, 개발팀은 콘텐츠 파일을 수집·매핑하는 수고를 덜었다.

FIG — UI Kit 구성, 노트북 표준화 구조 다이어그램 삽입 예정
Impact
  • 기획~오픈 리드타임 75% 단축
  • 이후 내부 공용 시스템으로 지속 운용 — 현재도 3년 이상 사용 중인 것으로 확인
Learning

영역을 넘나들며 문제를 해결했던 즐거운 경험이었다. 화면 구조를 보다가 떠올린 아이디어를 실제로 공유하고 채택될 수 있어서 좋았다.
