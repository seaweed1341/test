**배경 (Context)**
- 왜 이 프로젝트가 필요했나? (비즈니스 배경, 팀 상황)

- [ 이 문제가 왜 어려웠는지 — 기존 UX가 어떤 한계를 가졌는지 ]

**프로세스 (Process)**
- Figma 프로토타입에 리모컨 사방향키 조작을 그대로 구현 → 실제 환경에 가까운 UT 진행
- UT에서 '모두 동의' 버튼 이탈 패턴 발견
- [ UT는 몇 명 대상? 어떤 방법론? 발견한 인사이트가 구체적으로 뭐였나 ]
- 시선 흐름에 맞춰 버튼 위치·구조 개선
- [ Before/After 와이어프레임 또는 스크린샷 ]

**결과 (Impact)**
- 결제 완료까지 10초 단축
- [ 이 10초가 비즈니스적으로 어떤 의미인지 (이탈률 감소? 전환율 상승?) ]
- 24년 하반기 런칭 → 25년 상반기 업데이트까지 단독 주도

**회고 (Learning)**
- [ 이 프로젝트로 배운 것, 다음에 다르게 할 것 ]
